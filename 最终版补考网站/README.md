# 补考考场智能排考系统

帮助老师导入补考学生名单、管理科目和考场，并自动生成考试时间与考场安排。

## 功能

- 导入 CSV 学生名单，支持 UTF-8 和 GBK 编码
- 管理考试科目及笔试、机考类型
- 按学生冲突、考场类型和容量生成排班
- 按时间、教室、学生或科目查看结果
- 导出排班表和学生名单，并备份、恢复系统数据

## 本地运行

需要安装 Node.js。首次使用时在项目目录运行：

```bash
npm install
npm start
```

服务默认监听 8080 端口。启动后在浏览器打开 `http://localhost:8080`。
