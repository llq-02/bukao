## 1. 快速入门（5 步搞定）

| 步骤 | 操作 | 页面 |
|------|------|------|
| ① | 导入学生 CSV 文件 | 学生管理/导入 |

## 2. 页面功能详解

### 2.1 仪表盘

打开网站后首先看到的就是仪表盘，展示四张数据卡片：

| 卡片 | 含义 |
|------|------|
| 在读补考学生 | 已导入的补考学生总人数 |
| 考试科目总数 | 系统中的科目数量（导入 CSV 时自动提取） |
| 可用考场 | 已配置的考场数量 |
| 已生成排班记录 | 排班表中的总条目数（1 个学生 1 科 = 1 条） |

页面右下角有三个按钮：

- **导出备份**：把当前所有数据（学生、科目、考场、排班）导出为 JSON 文件，建议每次操作前备份一次。
- **恢复备份**：选择之前导出的 JSON 文件，一键还原所有数据。**会覆盖当前数据**。
- **清空数据**：一键清空全部数据，需确认。适合新一轮排考前清理。

---

### 2.2 学生管理 / 导入

**功能**：通过 CSV 文件批量导入补考学生名单。

**操作步骤**：
1. 准备 CSV 文件（格式见 [第 4 节](#4-csv-文件格式)）
2. 点击「选择文件」按钮，选中 CSV
3. 点击「上传导入」
4. 导入完成后下方表格显示已导入的学生列表

**表格列说明**：
- 序号：自动编号
- 学号：学生的正式学号
- 姓名
- 学院专业班级：格式为「学院-专业-班级」
- 补考科目：该学生需要补考的科目 ID 列表

**说明**：
- 系统自动识别 CSV 编码（UTF-8 / GBK），无需手动转换
- 同一学号的学生多行数据会自动合并（多门补考科目归到同一人名下）
- 导入时自动创建科目信息，无需提前手动添加科目

---

### 2.3 科目管理

**功能**：查看所有考试科目，区分笔试和机考。

**表格列说明**：
- ID：系统自动生成的科目编号（SUB1、SUB2…）
- 科目代码：如 `MATH101`
- 科目名称：如 `高等数学`
- 考试类型：`笔试(普通教室)` 或 `机考(机房)`

> 科目由 CSV 导入时自动创建，当前版本不支持手动增删科目。如需修改科目类型，请调整 CSV 文件中的 `IsLabExam` 列后重新导入。

---

### 2.4 考场教室管理

**功能**：配置笔试普通教室和机考机房的数量与容量。

**操作步骤**：
1. 填写「笔试普通教室」区块：
   - **教室数量**：可用普通教室间数（如 3）
   - **每间容量**：每间教室最多容纳的人数（如 50）
2. 填写「机考机房」区块：
   - **机房数量**：可用机房数（如 2）
   - **每间容量**：每间机房最多容纳的人数（如 30）
3. 点击「生成考场列表」
4. 下方表格显示生成的考场列表

**表格列说明**：
- 教室编号：R1、R2…（普通教室）/ LAB1、LAB2…（机房）
- 教室名称：如「教室1」「机房1」
- 类型：`普通教室(笔试)` 或 `机房(机考)`
- 容量限制：如「50人」

> 此页面配置的考场用于排班时的教室分配。如果不需要分配考场（仅名单模式），可以跳过此页面。

### 2.5 一键生成排班

**功能**：设置排班参数，系统自动生成排考表。

**参数说明**：

| 参数 | 说明 | 示例 |
|------|------|------|
| 考试起始日期 | 排考从哪天开始 | `2026-08-20` |
| 每日考试时间段 | 每天有哪些考试时段，格式 `HH:MM-HH:MM` | `08:00-10:00` |
| 笔试普通教室数量 | 同 2.4，留空或 0 则不排笔试考场 | `3` |
| 每间容量 | 每间普通教室容纳人数，留空默认 50 | `50` |
| 机考机房数量 | 留空或 0 则不排机考考场 | `2` |
| 每间容量 | 每间机房容纳人数，留空默认 30 | `30` |

**时间段操作**：
- 页面默认显示 5 个时间段（08:00-10:00、10:30-12:30、14:00-16:00、16:30-18:30、19:00-21:00）
- 点击「+ 新增时间段」可添加更多（每天最多 20 个）
- 点击每行「删除」可移除不需要的时段
- 可手动修改时段内容，如改为 `09:00-11:00`

**操作步骤**：
1. 设置起始日期（页面默认填入今天）
2. 调整时间段（增删改）
3. 填写教室数量和容量（**全部留空 = 仅名单模式**）
4. 点击「自动生成排班 / 名单」
5. 生成完成后下方显示结果信息

**生成结果信息示例**：
```
成功生成 1000 条排考记录（2026-08-20 ~ 2026-09-13，共 25 天 / 理论下限 25 天，已最优）
```
- **条数**：排班总记录数
- **日期范围**：从最早到最晚的考试日期
- **天数**：实际排期跨度
- **理论下限**：数学上最短的天数
- **已最优**：实际排期 = 理论下限，无法再压缩

### 2.6 查看排班结果

**功能**：以 4 种不同视角查看排班结果。

**4 种视图**：

| 视图 | 按钮名称 | 组织方式 | 适用场景 |
|------|---------|---------|---------|
| 1 | 按时间查看 | 按日期+时段分组 | 查看每天每场考什么 |
| 2 | 按教室查看 | 按考场分组 | 查看每个教室的考试安排 |
| 3 | 按学生查看 | 按学生分组 | 查看每个学生的考试日程 |
| 4 | 按科目查看 | 按科目分组 | 查看每门课的考试安排 |

**表格列说明**（所有视图相同）：
- 序号：组内序号
- 考试日期：如 `2026-08-20`
- 时间段：如 `08:00-10:00`
- 考场：如 `教室1`（仅名单模式下显示灰色「待安排」）
- 科目：科目代码+名称，如 `MATH101 - 高等数学`

- 姓名
- 班级

**排序规则**：所有视图的学生记录按**姓名拼音字母序**排列，同姓按学号排序。

**仅名单模式提示**：
如果排班时未填写教室信息，结果页顶部会显示黄色提示条：
> 当前为「仅名单模式」：考试日期和时间段已分配，只有「考场」列显示为灰色的「待安排」。

## 3. 两种排班模式

### 完整排班模式（填了教室数量）
- 系统自动分配：考试日期 + 时间段 + 考场
- 约束：同一学生同一时段只能考一门；笔试和机考考场隔离；单考场不超容
- 算法目标：在最短天数内排完所有科目（达到理论下限）
- 考场列显示真实教室名称

### 仅名单模式（教室数量全部留空或 0）
- 系统自动分配：考试日期 + 时间段
- 考场列显示灰色「待安排」
- 适用于：还没确定教室、只需先出考试时间表的场景
- 约束：同一学生同一时段只能考一门
- 理论下限 = `⌈每人最多科目数 ÷ 每天时段数⌉`

> 如需从「仅名单模式」升级到「完整排班模式」，回到「一键生成排班」页面，填写教室数量和容量后重新生成即可。

## 4. CSV 文件格式

**列顺序**（共 9 列）：
```
StudentID,Name,Campus,Department,Major,ClassName,CourseCode,CourseName,IsLabExam
```

| 列名 | 含义 | 示例 |
|------|------|------|
| StudentID | 学号 | 2025001 |
| Name | 姓名 | 张三 |
| Campus | 校区 | 南校区 |
| Department | 学院 | 计算机学院 |
| Major | 专业 | 软件工程 |
| ClassName | 班级 | 软2301 |
| CourseCode | 课程代码 | MATH101 |
| CourseName | 课程名称 | 高等数学 |
| IsLabExam | 是否机考 | 1=机考，0=笔试 |

**示例 CSV**：
```
StudentID,Name,Campus,Department,Major,ClassName,CourseCode,CourseName,IsLabExam
2025001,张三,南校区,计算机学院,软件工程,软2301,MATH101,高等数学,0
2025001,张三,南校区,计算机学院,软件工程,软2301,CS101,计算机基础,1
2025002,李四,南校区,计算机学院,软件工程,软2301,MATH101,高等数学,0
2025002,李四,南校区,计算机学院,软件工程,软2301,ENG101,大学英语,0
```

**说明**：
- 同一学号多行 = 一名学生补考多门课（系统自动合并）
- 文件编码支持 UTF-8（含/不含 BOM）和 GBK
- 第一行为表头，必须包含上述 9 个列名
- 建议用 Excel 编辑后另存为 `CSV UTF-8（逗号分隔）` 格式

## 5. 数据备份与恢复

### 导出备份
1. 进入「仪表盘」页面
2. 点击右下角「导出备份」
3. 浏览器自动下载 `exam_backup_YYYY-MM-DD.json` 文件

### 恢复备份
1. 进入「仪表盘」页面
2. 点击「恢复备份」→ 选择之前导出的 JSON 文件
3. 系统自动覆盖还原所有数据

### 清空数据
1. 进入「仪表盘」页面
2. 点击「清空数据」→ 确认弹窗 → 点「确认」
3. 所有学生、科目、考场、排班记录全部清空

> 建议每次大规模操作前先「导出备份」，操作失误时可「恢复备份」回滚。

## 6. 常见问题

### Q1：导入 CSV 后科目列表是空的？
检查 CSV 第一行表头是否包含 `CourseCode` 和 `CourseName` 列名，且对应列有数据。

### Q2：生成排班提示「请选择考试起始日期」？
在「一键生成排班」页面最上方的日期选择器中选一个日期。默认填入当天日期，如果浏览器拦截了自动填充需手动选。

### Q3：排班结果里考试日期排到了很远以后？
系统算法已优化为最短天数排完。如果天数仍然很多，可能原因：
- 学生数量多但每人补考科目多（每人科目数 ÷ 每天时段数 = 最低天数）
- 教室容量小或数量少（教室总容量限制了每天的吞吐量）
- 每天时间段太少（增加时段可减少天数）

可以尝试：增加每天时间段数量、增大教室容量、增加教室数量。

### Q4：「已最优」是什么意思？
说明实际排期天数 = 数学理论下限，已不可能再压缩。理论下限取以下三个维度的最大值：
- 普通教室并行天数 = `⌈Σ⌈每科学生数 ÷ 普通总容量⌉ ÷ (普通教室数 × 每天时段数)⌉`
- 机房教室并行天数 = `⌈Σ⌈每科学生数 ÷ 机房总容量⌉ ÷ (机房数 × 每天时段数)⌉`
- 学生冲突天数 = `⌈每人最多科目数 ÷ 每天时段数⌉`

### Q5：仅名单模式和完整模式有什么区别？
| | 仅名单模式 | 完整模式 |
|---|---------|---------|
| 教室数量 | 留空或 0 | 填写数字 |
| 考试日期 | ✅ 自动分配 | ✅ 自动分配 |
| 时间段 | ✅ 自动分配 | ✅ 自动分配 |
| 考场 | ❌ 显示「待安排」 | ✅ 分配真实教室 |
| 适用场景 | 只需出时间表 | 需要完整排考方案 |

### Q6：刷新页面后数据没了？
系统数据保存在服务器内存中，重启 Node 进程会清空。建议操作前用「导出备份」保存，重启后用「恢复备份」还原。

### Q7：想修改科目类型（笔试→机考）？
修改 CSV 文件中对应科目的 `IsLabExam` 列值（0→1），清空数据后重新导入即可。

### Q8：导出的 Excel 打开是乱码？
导出文件为 `.xls` 格式（HTML 表格伪 Excel），用 Microsoft Excel 或 WPS 打开即可。如果用其他软件打开出现乱码，尝试用 Excel 打开后另存为标准 `.xlsx`。
